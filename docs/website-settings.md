# 网站设置与 1Panel 行为对应

网站列表点击「配置」，进入按功能独立保存的设置页。参考版本与现有组件保持一致：1Panel `3adee9445897aa41c0160b4f805a9b1f43f712ac`。列表、抽屉、确认、状态、分页和代码预览继续使用已复用的 1Panel 组件。源码分为独立 Vue 组件、类型化 DTO、服务和渲染器，没有把全部功能写入网站编辑器。

| 设置 | 对应行为 |
| --- | --- |
| 域名设置 | 列表展示域名、端口、SSL；抽屉批量添加；SSL 开关；删除确认；禁止删除最后一条绑定 |
| 网站目录 | 显示网站根目录，选择已有运行子目录，保存并应用；可直接进入文件管理 |
| 默认文档 | 每行一个文件，严格按填写顺序查找 |
| 反向代理 | 规则创建/编辑/启停/删除；前缀、精确、优先前缀、区分/不区分大小写正则匹配；每条规则一个 HTTP(S) 目标 |
| 代理高级配置 | 发送 Host、SNI、上游证书验证、超时；服务端缓存、浏览器缓存三种模式、内容替换、规则级 CORS；独立缓存设置与清理 |
| 跨域设置 | 启用、来源、方法、请求头、凭据、OPTIONS 预检；网站级设置可由代理规则覆盖 |
| HTTPS | 显式启用 HTTPS、绑定已有服务器证书；HTTP 跳转 HTTPS、两者同时支持、仅 HTTPS；HSTS、子域、TLS 协议/套件、HTTP/2、HTTP/3 |
| 真实 IP | 信任来源 IP/CIDR、X-Forwarded-For/X-Real-IP/CF-Connecting-IP 或自定义请求头；开启 real_ip_recursive |
| 重定向 | 域名、路径、404 三类；301/302、目标 URL、保留路径；404 支持跳转首页；启停确认和删除确认 |

修改网站名称使用设置页右上角「修改名称」。选中的分区保存在地址 hash，刷新仍可进入同一区域。保存期间禁用分区切换，防止新分区读取到尚未提交的旧 revision。外部更新导致版本过期时，保留本地编辑并报错；点击「重置」采用最新快照。表单编辑不会因后台轮询刷新而被覆盖。

## 域名与端口

`bindings` 是权威绑定列表，`domains` 是按绑定去重的兼容字段。域名不含协议或端口，国际化域名使用 punycode。相同域名可以在不同网站的不同端口使用；同域名、同端口不能重复占用。与 1Panel 的 server 组织一致，一个网站的 server_name 和监听端口集合共享，不为每个域名/端口组合创建不同内容。

80 为逻辑 HTTP 端口、443 为逻辑 HTTPS 端口，分别对应启动参数 `-http-bind` 与 `-https-bind` 的实际发布地址；HTTPS 启用后自动增加默认 HTTPS 监听。其他绑定端口直接作为宿主机端口发布，HTTP 继承 http-bind 的 IP，SSL 继承 https-bind 的 IP。SSL 标记在网站启用 HTTPS 后生效。443 必须使用 SSL；80 不启用 SSL。不同网站在同一 TCP 端口上不能混用 HTTP 与 HTTPS。

域名删除若影响已有重定向来源，须先修改或删除该重定向。启用的网站证书需覆盖全部绑定域名，沿用现有引用保护和证书验证逻辑。

自定义端口与 L4、HTTP/HTTPS、HTTP/3 UDP 发布统一检查。发布变化会重建托管容器，并短暂中断全部网站和代理连接；失败会恢复原容器及配置。只改变域名、目录、默认文档、代理目标或请求处理通常仅重载。

## 目录与默认文档

网站文件位于 `data/sites/<id>`。运行目录 `/` 表示网站根目录，`/public` 表示其子目录。先通过文件管理写入 `public/home.html` 等文件，再刷新目录列表并选择 `/public`。不存在的目录、隐藏目录、路径穿越和符号链接均不能作为运行目录。Nginx 静态访问启用 disable_symlinks，避免通过链接读取其他站点。

默认文档可以为 `home.html`、`index.html`、`index.htm` 等相对路径，顺序影响首页选择。文档不能含 PHP 类型文件或 Nginx 指令。各网站共用管理器 UID/GID，保持既有容器权限模型，不提供 1Panel 面板式的系统用户/组修改。

## 反向代理

代理路径匹配与 Nginx/1Panel 相同：无修饰符为前缀匹配，`=` 为精确匹配，`^~` 为优先前缀匹配，`~`/`~*` 为正则匹配。正则使用镜像的 PCRE 编译，语法错误在应用时拒绝并保留旧部署。

目标 `http://origin:9000` 不含 URI，保留原始请求路径；目标 `http://origin:9000/backend/` 带 URI，替换匹配的前缀。例如 `/api/item?x=1`、匹配 `/api/`、目标 `/backend/`，上游收到 `/backend/item?x=1`。正则代理目标不能带 URI。目标域名在应用时解析。127.0.0.1 指容器自身，宿主机服务使用 `host.docker.internal` 且需监听容器可达地址。

默认发送 Host 为 `$host`，还支持 `$http_host`、`$proxy_host` 或明确域名/IP[:端口]。转发 Upgrade/Connection，支持 WebSocket 升级。新建 HTTPS 代理时自动开启 SNI，可指定 SNI 名称及上游证书验证开关。与 1Panel 新建代理默认值一致，上游证书验证默认关闭；旧单源代理迁移保留原来的开启状态。开启验证时使用镜像系统 CA，验证失败返回 502。

服务端缓存按网站隔离，规则键包含规则 ID。缓存区默认共享内存 5 MiB、磁盘容量 1024 MiB、不活跃过期 60 分钟，可以在「缓存设置」调整；每条规则另设响应缓存时间。带 Authorization、Cookie、Upgrade 的请求和 Set-Cookie 响应不写入共享缓存。浏览器缓存与 1Panel 一致：正数设置 expires；0 不修改上游策略；-1 强制过期。缓存清理仅删除当前网站的缓存文件。

内容替换使用 sub_filter，按 1Panel 对全部响应类型进行多次替换；向上游发送空 Accept-Encoding，避免压缩内容影响替换。替换文本按 Nginx 模块处理变量，未知变量在配置校验时拒绝。代理规则不包含上游池、负载均衡或 PHP 运行环境。

## CORS、真实 IP 与 HTTPS

CORS 启用时采用 1Panel 的默认方法及预检开关。来源支持 `*`、明确来源列表，或显式 `$http_origin`。多个来源使用 map 匹配当前 Origin，未匹配时不发送允许来源。凭据模式不能使用 `*`。网站设置作为默认，启用规则级 CORS 时覆盖；上游同名 CORS 响应头被移除，避免重复响应头。错误页和带 CORS 的代理位置也保留 HSTS。这里只管理网站响应，不放宽管理 API 的跨站写入保护。

真实 IP 只从声明的 IP/CIDR 读取请求头，并递归选择最后一个非信任地址。不在信任列表内的连接不能借请求头覆盖客户端 IP。

新界面启用 HTTPS 默认勾选 HSTS；旧站点迁移保持原 HSTS 行为。HTTPToHTTPS 返回 301，使用实际 HTTPS 发布端口；HTTPAlso 提供明文与 TLS 内容；HTTPSOnly 对 HTTP 连接返回 Nginx 444。绑定 mTLS 时禁止 HTTPAlso，避免明文绕过客户端证书验证。mTLS 的 CA、CRL、吊销和会话设置沿用原实现。

HTTP/3 在 TLS 端口启用 QUIC 并发布相应 UDP 端口，Alt-Svc 根据请求 Host 中的端口或默认 HTTPS 发布端口生成。镜像必须含 http_v3 模块；默认镜像已具备。应用前仍由实际镜像检查模块和指令兼容性。

## 重定向

- 域名：匹配已绑定来源域名；通配域名按 1Panel 的单个 DNS 标签匹配。保留路径时直接在目标后附加完整 `$request_uri`，包括查询参数；目标通常填写不带末尾 `/` 的站点地址。
- 路径：按 `^路径(.*)` 匹配；保留路径时追加 `$1`，保留原查询参数；关闭时丢弃来源路径和查询参数。
- 404：覆盖网站的 404 页面处理，跳转指定 URL，或返回首页。其他错误页面不受影响。首页自身必须可访问，以免循环跳转。

规则创建后名称、类型不可修改。已被规则占用的域名不能再创建重复域名跳转。停止规则保留配置，删除需要确认。路径跳转只执行 301/302 外部重定向，不提供已排除的伪静态编辑。

## 配置文件与响应头

网站设置中的“配置文件”复用固定上游的 `config/resource/nginx/index.vue` 页面和现有 CodeMirror 组件。读取的是当前网站草稿，使用网站公开端口和 `/srv/resty/current` 稳定资源引用；部署时转换为容器端口和不可变版本路径，不直接改动运行中生成文件。停用的网站也可编辑。

保存按“1Panel 语法解析 → 类型化 GUI 配置 → 重新生成 → 完整 AST 比对”执行。比较忽略注释、排版和可还原的引号，允许移动响应头声明；未知或重复指令、不可表达的上下文、无法一致表示的 HTTP/HTTPS 共享字段、受管片段改动均拒绝。报错包含位置，拒绝时不改变 revision 或运行配置，编辑器保留未保存内容。上游解析器的最小补丁拒绝缺失/额外右括号、独立终止符与尾部垃圾，来源及补丁见 [复用清单](../web/panel/manifest.json)。

支持映射域名、网站内运行目录、默认文档、真实 IP、TLS 协议/套件/HTTP2/HSTS、已有代理的地址/Host/超时/SNI/证书验证/缓存时间，以及自定义响应头与目录保护。监听绑定、HTTPS 访问模式、mTLS、Lua、重定向及未覆盖的复杂改动使用对应 GUI 模块；直接改动后无法完整往返时明确报错。HTTP/HTTPS 共用的字段必须一致，不能表达为两个互相冲突的值。

“响应头与安全”提供同一份结构化数据的表单。响应头 `{scope,tls,name,value,always}` 中，scope 为 `server`、`root`、`proxy:<规则 ID>` 或 `error:<状态码>`；遵循 OpenResty 的 add_header 继承规则，不能假定 server 头会覆盖已有 location 头。重复头保持声明顺序；未启用协议或规则的设置保留。CORS/HSTS/Alt-Svc/Vary 由已有模块维护，不能通过自定义头重复定义。

目录保护允许修改 `disable_symlinks on/off`，或移除隐藏文件拒绝规则；对应 `security.followSymlinks` 和 `security.allowHiddenFiles`。默认均为 false，保留原有保护。PHP 拦截、内部错误页路径隔离以及管理器的文件 API 边界仍受管，不能借此增加 PHP 或任意容器文件管理。

成功保存仅持久化 GUI 数据，注释和排版规范化。运行中的引擎随后执行 OpenResty/LuaJIT 校验并重载；校验失败保留旧部署与可修正草稿。停止的引擎只保存草稿，下次应用时校验。跨页面修改使用读取配置时的 revision，冲突必须重新加载。后续 GUI 保存不会覆盖已导入的响应头及安全选项。

## 兼容与备份

配置导出 schema 保持 2，新增字段作为兼容的结构化配置保存在 SQLite 资源文档中，无需新增 SQL 迁移。旧站点自动获得 80 端口绑定、根运行目录、index.html、原 HTTP 到 HTTPS 行为；原单源代理迁移为 default 规则，保留 SNI 和上游证书验证。空代理规则列表是明确状态，删除 default 后不会重新生成。各分区只更新自身字段，共用全局 revision 防止覆盖并发修改。

配置、域名、目录选择、代理、CORS、HTTPS 与独立 mTLS、真实 IP、重定向和缓存参数全部纳入本地/S3 完整备份。`data/cache` 仅保存可再生成的缓存，不进入备份。恢复后引擎保持停止，检查并应用后再启动。

容器 spec 更新为 3，增加独立可写缓存挂载。旧版本容器首次应用会重建一次。runtime、网站文件和容器根文件系统仍只读，只有缓存目录与临时目录可写。管理器仍是独立 Go+内嵌 Web 程序，不加入账户、授权、系统面板或防火墙管理。配置预览为只读，修改通过类型化表单完成。

HTTPS 页已替换为原版 1Panel 组件；客户端 CA 和 mTLS 开关移至独立 mTLS 模块。原先此处描述的客户端 CA 控件不再出现在 HTTPS 表单中，完整说明见 [证书模块](certificates.md)。
