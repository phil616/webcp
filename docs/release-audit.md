## 发布前提与边界

工作目录当前不是 Git 仓库；本地包的 commit 显示 unknown。正式对外发布前应将核验后的源码纳入实际仓库，从对应提交和版本标签重建。本轮不创建远端标签或 Release。

本地检查不等同于 GitHub 托管 runner 已执行；ARM64 通过交叉编译验证，若未在 ARM64 硬件运行，不写为运行验证。HTTP/3 当前覆盖配置、端口和 Alt-Svc，尚未完成端到端 QUIC 客户端验证。部署/恢复验证进程中断回滚，不宣称断电时 Docker 与文件系统跨系统原子性。

运行时镜像按具体部署版本另行核验；本次执行实际 OpenResty 功能测试，没有执行容器镜像层的完整 CVE 扫描。Go/npm 扫描通过不等于对所有自建镜像作安全保证。

系统仍为单机、可信管理员使用；部署与备份由 Manager 串行协调。没有通过新增多租户、PHP、运行环境或商业授权扩大本次范围。
